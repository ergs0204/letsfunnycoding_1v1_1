## str

`x="hiabcdefgaaahi"`

### count 數出現次數
`x.count("a")` => 4

`x.count("hi")` => 2

### x.find x.index 找出現的位子  
`x.find("bc")` => 3

### 看是不是數字
`x.isdigit()` 

### 看是不是全大寫、全小寫  
`x.isupper()`  

`x.islower()`  

### 換成大小寫  
`new_text=x.upper()`  

`new_text=x.lower()`

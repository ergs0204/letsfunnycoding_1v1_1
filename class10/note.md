# open
open(檔名,模式)

## 模式
- a: append(新增在結尾)
- r: read(讀檔案)
- w: write(整個檔案重寫) 小心覆寫

```py
with open("example.txt","w") as f:
    f.write("要寫進檔案的內容")
```
